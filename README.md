# 奇门遁甲 · 四盘罗盘

一款给初学者用的奇门遁甲排盘应用。不用背口诀，把盘转起来，答案自己会浮出来。

## 它解决什么

传统排盘要在纸上画九宫、布六仪、找值符值使，一步算错整盘作废，对刚入门的人几乎是一道墙。这里把整套流程做成能用手摸的四层转盘：**拖动外圈，松手落宫**，天地人神四盘像实体罗盘一样咬合转动，转到哪、落在哪一宫，一眼就看得见。

## 主要特性

**拖动排盘**

地盘、天盘、人盘、神盘四层各自独立旋转。按住任意一层拖动，松手自动吸附到最近的宫位，不会停在不三不四的角度。方位沿用传统排法，南上北下，0° 正对离九宫。想理解"天盘怎么随值符走"，亲手上手转两圈比看十页讲义快。

**一键起局**

在日历里点一个日子、拨一下时辰，拆补法自动定阴阳遁、定三元、布地盘、找旬首值符值使，整盘一次排好。也可以切到阴遁手动改，对照着看两种局的差别。

**克应随手可查**

点击任意一宫，十干克应 81 条、八门克应 135 条就地展开。天盘干配地盘干是什么关系、门与门相遇怎么断，不用再翻书对页，盘面就是目录。查的时候盘不会乱，看完接着转。

**格局判断**

九遁、常用吉格凶格在盘面同步标出。哪些组合成格、成的是吉是凶，直接给结论，再点开看依据。

**纸面观感**

暖羊皮纸底色，宋楷两套字体，配色克制到只有一种强调色。长时间盯着看眼睛不累，也不会一眼看出是个"App"。

**完全离线**

不联网、不申请任何一项系统权限、没有广告和内购。所有盘面和数据都打包在安装包里，飞行模式下照常使用。

## 三步上手

1. 打开应用，默认是当天的局
2. 想换时间就点日历和时辰；想自己试，直接拖转盘
3. 点某一宫，看这一宫的克应和吉凶

## 安装

Android 7.0 及以上。装好即用，不注册、不登录。

## 数据与授权

十干克应、八门克应条目依据张志春《神奇之门——奇门遁甲大解谜》（2011）整理，保留原书条目结构与表述，仅清理排版空白。这部分文字内容的著作权不属于本工程，公开分发前请自行确认授权范围。排盘算法依据拆补法体系实现，节气与干支口径为北京时间。

本工程尚未选择开源许可协议。

Gradle 9.5.0、Android Gradle Plugin 9.3.0、JDK 17、compileSdk 37，`gradle assembleRelease` 出包。签名密钥不随仓库分发，密码从环境变量读取。
